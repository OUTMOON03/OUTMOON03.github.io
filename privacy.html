Privacy Policy

Last updated: October 24, 2026

This policy describes how the Key Cuts publishing application ("the App") handles information. The App is an internal tool operated by Key Cuts to upload short videos to Key Cuts' own accounts on YouTube, TikTok, Instagram and Facebook. It is not offered to the public.

Information the App accesses

  • Basic profile information of the Key Cuts accounts that the operator authorizes (account name and ID), used only to confirm which account a video is published to.
  • Permission to upload and publish videos, titles, descriptions and hashtags to those accounts.
  • The publishing result (video ID and link), used to confirm that the upload succeeded.

The App does not access, collect or store data about other users, viewers or followers, and does not read messages, comments or contacts.

How information is stored

Access tokens issued by each platform are stored only on the operator's own computer and are never shared, sold or transferred to third parties. They are used solely to publish content to Key Cuts' own accounts.

Google / YouTube

The App uses YouTube API Services. By using the App you are also subject to the YouTube Terms of Service and the Google Privacy Policy. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at Google security settings.

TikTok, Instagram and Facebook

The App uses the TikTok Content Posting API and the Meta (Instagram and Facebook) Graph API only to publish videos to Key Cuts' own accounts. Access can be revoked at any time from each platform's app and security settings.

Data deletion

To request deletion of any data or revocation of access, contact keycuts0@gmail.com. Stored tokens are deleted within 7 days of the request.
